# Changelog

本项目使用简化的 Keep a Changelog 结构。正式版本发布后再补充版本号和日期。

## Unreleased

### Added

- 建立产品、架构、契约、质量、运维、计划和治理文档框架。
- 在 `03_SourceCode` 源码项目根目录增加项目入口、编码代理规则、环境变量示例和生成文件忽略规则。
- 接受 ADR-0002：Web 视频迁移到浏览器 WebCodecs 离线逐帧导出。
- Web 新增复古硬件风格的视频导出设置、预计信息、逐帧进度、帧数和取消操作。
- Web 新增快速/高清/精细画质与源/24/30/60 FPS 选择，以及输出规格单测。
- Web 电视底部新增“屏幕反光”实体开关，可独立切换 CRT 玻璃高光且不影响保存结果。
- 增加项目内可复现的横向、竖向有声视频和静态图片测试素材。

### Changed

- Web 项目已迁移为 Vite/npm，并使用 Mediabunny、WebCodecs、Worker 和 OffscreenCanvas 离线处理视频。
- Web 图片保存保持原逻辑；视频保存优先 H.264/MP4，回退 VP9/WebM，MediaRecorder 仅作为明确提示后的兼容路径。
- Web 预览与离线输出共用栅格渲染器；视频按目标分辨率直接重绘并保持输入比例、偶数尺寸和黑色背景。
- Web 音频优先直接复用，必要时转码 AAC/Opus，无法处理时显示静音提示。

### Known limitations

- VP9/WebM 自动降级和不兼容音轨转码/静音仍缺目标设备动态验证。
- Web 当前使用内存缓冲封装完整视频，超长或高分辨率素材仍需压力测试。
- 三端分别维护渲染常量与部分算法，仍需要自动化一致性测试。
- 小程序视频处理 API 地址仍在页面脚本中配置。
