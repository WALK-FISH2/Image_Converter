# 渲染参数契约

本文件定义跨 Web、小程序和 Server 的参数名称与语义。端侧控件范围可以因设备能力不同而收窄，但同一值必须表达同一含义。

## 参数表

| 参数 | 类型 | 标准默认值 | 有效值/范围 | 语义 |
| --- | --- | --- | --- | --- |
| `cols` | integer | Web/Server 96；小程序 50 | 契约 44-160 | 横向栅格单元数，越大越精细。 |
| `scale` | number | 1.00 | Server 0.40-1.80；UI 当前 0.60-1.60 | 输入内容在栅格区域中的等比缩放。 |
| `contrast` | number | 1.18 | 0.70-1.80 | 围绕中灰调整亮暗差异。 |
| `mode` | enum | `ascii` | `ascii`, `dots`, `halftone` | 栅格单元类型。 |
| `charset` | enum | `dense` | `dense`, `block`, `line` | 字符模式使用的亮度字符阶梯。 |
| `tone` | enum | `green` | `green`, `amber`, `paper` | 前景与 CRT 局部色调。 |
| `invert` | boolean | false | true/false | 在对比度和抖动后反转亮度。 |
| `dither` | boolean | true | true/false | 启用 4x4 有序抖动。 |
| `glow` | boolean | true | true/false | 启用单元局部辉光。不得改变背景基准。 |

`charset` 在 `dots` 和 `halftone` 模式下保留状态但不应影响输出。

## 当前端侧范围

| 参数 | Web | MiniProgram | Server |
| --- | --- | --- | --- |
| `cols` | 48-160，步长 4 | 44-132，步长 4 | 强制限制 44-160 |
| `scale` | 0.60-1.60，步长 0.05 | 0.60-1.60，步长 0.05 | 强制限制 0.40-1.80 |
| `contrast` | 0.70-1.80，步长 0.02 | 0.70-1.80，步长 0.02 | 强制限制 0.70-1.80 |

小程序较低的默认列数是布局和真机小字号可见性的有意选择，不属于参数语义差异。

## 字符集

字符必须按从暗到亮排列。前导空格是暗部层级，不是格式空白。

- `dense`：长 ASCII 亮度阶梯。Server 中的当前定义由用户校准，修改时不得用旧短集合覆盖。
- `block`：块元素亮度阶梯。浏览器/小程序依赖字体绘制，Server 需要程序化块字形支持。
- `line`：由空格、点、横线、冒号、等号等逐渐增强的线性集合。

三个运行端的字符集必须一并核对。Server 的内置 5x7 字形覆盖有限；未知字符回退策略不能被误认为与浏览器字体等价。

## 色调

| ID | UI 名称 | 背景基准 | 前景代表色 |
| --- | --- | --- | --- |
| `green` | 绿屏 | 近黑 | 绿色荧光 |
| `amber` | 琥珀 | 近黑 | 琥珀黄色 |
| `paper` | 冷白 | 近黑 | 冷白/浅青 |

保存文件背景必须保持黑色基准。色调只用于可见栅格单元和受控局部效果。

## 序列化

小程序通过 `wx.uploadFile` 的 `formData` 发送字符串：

- 数字使用十进制，例如 `"50"`、`"1.00"`、`"1.18"`。
- 布尔值使用 `"true"` 或 `"false"`。
- enum 使用上表中的小写 ID。

Server 对非法 enum 使用默认值，对数值执行限制。调用端不应依赖 Server 修正明显非法输入。

## 已知契约差异

- Server 当前接收 `glow` 字段，但逐帧像素渲染尚未使用该值。此项记录为 `TASK-RENDER-002`。
- 开屏演示使用内部 `DEMO_OPENING_SCALE` 和真机可见性补偿，这些不是公开参数，也不能发送到视频 API。
