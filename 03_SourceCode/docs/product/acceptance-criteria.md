# 验收标准

## 通用测试素材

至少准备以下输入：

- 横图：16:9 或接近 1.78。
- 竖图：9:16 或接近 0.56。
- 方图：1:1。
- 横向有声视频、竖向有声视频、无声视频各一个。
- 同时包含暗部、中灰、亮部和细线的图像。

## 核心功能

| 验收编号 | 对应需求 | 通过条件 |
| --- | --- | --- |
| AC-CORE-001 | REQ-CORE-001/002 | 载入图片或视频后，屏幕主体来自用户媒体，不再显示开屏演示。 |
| AC-CORE-002 | REQ-CORE-003 | 三种模式的几何单元明显不同，切换后不需要重新载入媒体。 |
| AC-CORE-003 | REQ-CORE-004 | DENSE、BLOCK、LINE 在字符模式下产生明显不同的亮度阶梯或笔画语言。 |
| AC-CORE-004 | REQ-CORE-005/006/007 | 每个参数可操作，读数与状态正确，改变后画面方向符合参数定义。 |

## 图片

| 验收编号 | 对应需求 | 通过条件 |
| --- | --- | --- |
| AC-IMG-001 | REQ-IMG-001 | 横图、竖图、方图导出宽高比与输入显示宽高比误差不超过 1%。 |
| AC-IMG-002 | REQ-IMG-001 | 圆形测试图处理后仍接近圆形，不出现明显横向或纵向压缩。 |
| AC-IMG-003 | REQ-IMG-002 | PNG 只包含栅格输出，不包含按钮、外壳、导航栏或被裁切的主体。 |
| AC-IMG-004 | REQ-VID-004 | 输出背景视觉为黑色；绿屏仅体现在发光单元和受控局部辉光。 |

## 视频

| 验收编号 | 对应需求 | 通过条件 |
| --- | --- | --- |
| AC-VID-001 | REQ-VID-001 | 暂停查看任意三帧，原始画面均由所选字符/点/半调单元重建，而不是原视频叠色。 |
| AC-VID-002 | REQ-VID-002 | 页面播放和保存文件均包含从开始到结束的连续动态内容，不是缩略图或单帧。 |
| AC-VID-003 | REQ-VID-003 | 横、竖视频输出显示比例与输入误差不超过 1%；编码偶数尺寸调整不得产生可见拉伸。 |
| AC-VID-004 | REQ-VID-004 | 视频黑场区域与图片黑色背景一致，不存在整幅绿色底光。 |
| AC-VID-005 | REQ-VID-005 | 有声视频输出可听到音频且与画面无明显错位；无声视频可以正常输出。 |
| AC-VID-006 | NFR-PERF-002 | 处理中、完成、失败状态明确；处理期间重复点击保存不会产生错误文件。 |

## Web

| 验收编号 | 对应需求 | 通过条件 |
| --- | --- | --- |
| AC-WEB-001 | REQ-WEB-001 | Chromium 当前稳定版完成图片、视频、调参和保存全流程。 |
| AC-WEB-002 | REQ-WEB-002 | 开屏笑脸主体完整、接近既定 Web 构图，不因上传媒体比例修复而变窄。 |
| AC-WEB-003 | REQ-UI-004 | 1366x768 和 1920x1080 下无按钮文字裁切、重叠和面板溢出。 |
| AC-WEB-004 | REQ-WEB-003/NFR-PERF-003 | 10 秒视频导出不等待隐藏视频完整播放；处理循环不绑定真实播放时钟。 |
| AC-WEB-005 | REQ-WEB-003/005 | 导出帧按目标分辨率直接重绘，字符、点阵、半调边缘明显清晰于旧 MediaRecorder 输出。 |
| AC-WEB-006 | REQ-WEB-005 | 三个画质档对横、竖视频均保持输入比例，宽高为偶数，低分辨率输入不被放大。 |
| AC-WEB-007 | REQ-WEB-006 | 降帧率后视频时长误差不超过一帧；24/30/60 选项按 29.5/59.5 容差正确禁用。 |
| AC-WEB-008 | REQ-WEB-004 | Chrome 和 Edge 优先选择通过能力检测的 MP4/H.264；不支持时选择 WebM/VP9。 |
| AC-WEB-009 | REQ-WEB-007/008 | 设置面板显示预计信息；导出显示百分比和帧数、支持取消、禁止重复提交且结束后恢复预览状态。 |
| AC-WEB-010 | REQ-WEB-009 | 兼容音轨保持音画同步；需要转码时输出 AAC/Opus；无法保留时导出前明确提示无声结果。 |
| AC-WEB-011 | REQ-CORE-003/004/005/006/007 | 字符、点阵、半调均按开始导出时的列数、缩放、对比度、字符集、反相、抖动、辉光和色调生成。 |
| AC-WEB-012 | REQ-IMG-001/002 | 新视频导出模块不改变图片保存文件的尺寸、比例和视觉结果。 |
| AC-WEB-013 | REQ-WEB-010 | 电视底部显示“屏幕反光”按钮；默认开启，点击后玻璃反光完全隐藏，再次点击恢复，按键状态与 `aria-pressed` 同步且不改变导出内容。 |

## 小程序和真机

| 验收编号 | 对应需求 | 通过条件 |
| --- | --- | --- |
| AC-MP-001 | REQ-MP-001 | 常见手机宽度下屏幕、左侧按钮、扫描参数和保存按钮均不重叠、不越界。 |
| AC-MP-002 | REQ-MP-003 | 处理完成后页面显示可播放的 `video`，保存到相册的是 MP4 而不是预览帧。 |
| AC-MP-003 | REQ-MP-004 | 开屏完整进入屏幕，缩放读数仍为 `1.00`；用户媒体不继承开屏内部缩放。 |
| AC-MP-004 | REQ-XPLAT-001/002 | 开发者工具与 Android/iOS 真机的主体轮廓一致，亮区内部无大片意外空洞。 |
| AC-MP-005 | REQ-XPLAT-002 | 在 50 列下分别测试字符、点阵、半调，低亮度非黑区域仍有可见单元。 |

## 验证记录要求

验收后在 `docs/quality/compatibility-matrix.md` 记录日期、平台、版本、输入素材和结果。失败项进入 `docs/planning/tasks.md`，不得只在聊天记录中保留。
