# 产品规格

## 1. 产品形态

IC-84 的第一屏就是可操作的视觉终端，不设置营销型落地页。Web 端采用横向桌面控制台，小程序采用纵向电视机布局；两者共享产品语言和参数语义，但不要求逐像素复制布局。

屏幕始终是视觉中心。外壳、按键和面板为操作提供真实硬件感，但不能挤压、遮挡或改变输出内容比例。

## 2. 初始状态

- 启动后显示既定的抽象笑脸/摇椅栅格动画。
- 默认模式为字符，字符集为 DENSE，色调为绿屏。
- 默认开启抖动与辉光，关闭反相。
- Web 默认 96 列；小程序默认 50 列，以适应手机 Canvas 和左侧控制区。
- 小程序开屏素材使用内部适配缩放，使完整构图进入竖屏，但界面缩放读数保持 `1.00`；该适配不得用于用户上传媒体。

## 3. 图片流程

1. 用户点击载入/插入图片并选择相册或本地文件。
2. 系统读取原始显示宽高比，以 contain 方式放入处理区域，允许黑边但不允许拉伸。
3. 当前模式和参数即时重新渲染。
4. 用户点击保存后得到 PNG。
5. 保存内容只包含处理结果，不包含控制台外壳和按钮。

## 4. 视频流程

### Web

1. 浏览器读取本地视频并连续抽取当前帧。
2. Canvas 使用当前参数实时重绘。
3. 点击 SAVE 后打开复古硬件风格的导出设置面板，不立即开始保存。
4. 面板提供画质、帧率、预计尺寸、预计编码格式、预计大小、取消和开始导出。
5. 开始后暂停实时预览的资源竞争，在 Worker 中用媒体容器库解封装，并通过 WebCodecs 离线解码帧。
6. 每个选中时间戳的帧在独立高清 OffscreenCanvas 上按当前全部参数重新渲染，不从页面 CRT Canvas 截图或放大。
7. 使用 `VideoEncoder.isConfigSupported()` 选择编码：优先 MP4/H.264 与可变码率、优先硬件；失败时选择 WebM/VP9。
8. 音频按“兼容包直通、AAC/Opus 转码、无声告警”顺序处理。
9. 导出期间显示百分比和当前帧数，禁止重复提交并允许取消。
10. 完成或取消后恢复视频原播放位置和播放/暂停状态。
11. 不支持 WebCodecs 的环境明确提示后，可使用现有 MediaRecorder 兼容路径；该路径不是主要方案。

#### 画质档

- 快速：目标边界 1280x720，建议视频码率 6 Mbps。
- 高清：目标边界 1920x1080，建议视频码率 14 Mbps，默认选择。
- 精细：保持原始尺寸但不超过 2560x1440，建议视频码率 24 Mbps。
- 所有档位按输入显示比例 contain 到目标边界，输出宽高为偶数；输入小于边界时不放大。

#### 帧率档

- 跟随原视频：保留源平均帧率和时间戳节奏。
- 24 FPS、30 FPS、60 FPS：按时间戳均匀选帧，不改变媒体时长。
- 固定帧率高于源帧率时禁用；29.97 FPS 允许选择 30，59.94 FPS 允许选择 60。
- 源帧率低于 29.5 FPS 时默认改选“跟随原视频”，否则默认 30 FPS。

### 小程序

1. 用户选择最长 60 秒的视频。
2. 页面显示缩略图和处理中状态，将视频及当前参数上传至 `POST /api/process-video`。
3. Server 使用 FFprobe 读取显示比例，FFmpeg 解码帧，Node 渲染器重建每帧，再由 FFmpeg 编码 MP4 并尽可能复用音频。
4. 小程序下载处理结果到临时文件，通过页面内 `video` 组件自动循环播放。
5. 保存操作将完整 MP4 写入系统相册。

## 5. 参数行为

- 列数：控制横向采样单元数量。值越大细节越多、单元越小、真机可见性风险越高。
- 缩放：控制输入内容在栅格区域中的占比。`1.00` 表示正常适配，不改变输入宽高比。
- 对比度：围绕中灰调整亮暗差异。
- 反相：在亮度映射后执行 `1 - brightness`。
- 抖动：使用有序矩阵扰动亮度，改善低色阶层次。
- 辉光：控制显示单元的发光感；不得将黑色背景整体染绿。
- 字符集：仅对字符模式生效。
- 色调：改变前景发光颜色和屏幕基调，不改变几何结构。

详细范围见 `docs/contracts/rendering-parameters.md`。

## 6. 渲染模式

- 字符：每个采样单元按亮度选择一个字符，使用等宽排布。
- 点阵：每个采样单元绘制圆点，以半径和亮度表达灰阶。
- 半调：每个采样单元绘制交错角度的短矩形/点形，以尺寸表达灰阶。

在真实手机上，低亮度非黑单元必须保留最低可见尺寸或透明度。辉光应按模式分别设置，不能让小点和半调单元被扫描线、暗角或透明叠层吞掉。

## 7. 保存与比例

- 比例指考虑视频 sample aspect ratio 后的显示宽高比。
- 输出尺寸可以为编码需要调整到偶数，但比例误差应控制在验收容差内。
- 竖图输出应保持竖向，横图输出应保持横向，方图应保持接近方形。
- 黑边用于 contain 适配时可以存在，但不得通过非等比缩放消除黑边。
- 图片与视频的栅格区域应使用一致的黑色背景基准。
- Web 视频导出 Canvas 与页面 CRT Canvas 的尺寸和生命周期相互独立，必须按目标尺寸直接重绘每帧。

## 8. 状态和错误

- 图片/视频选择取消：保持当前内容，不弹出失败提示。
- 视频处理中：禁止重复保存，显示明确处理中状态。
- Web 视频导出取消：终止解码/编码、释放 VideoFrame/编码器/Worker，不生成不完整下载文件，并恢复预览状态。
- 上传或处理失败：保留可恢复界面，显示失败提示，允许重新选择。
- 结果下载失败：可尝试直接使用服务 URL 播放；仍失败时提示用户检查网络和服务地址。
- 相册权限被拒绝：引导用户进入小程序设置重新授权。

## 9. 不在当前规格内

批量处理、云端项目、参数预设同步、服务鉴权和长期媒体托管不属于当前基线，需作为新需求评审。
